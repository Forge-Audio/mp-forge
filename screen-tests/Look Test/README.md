# Look Test

A test plugin for the workbench's look editor. It is Akai's starter effect (gain, tone and mix), unchanged
in sound. Its screen is what is being tested.

- **STYLED** has everything the editor's look file can ask for: a background with a fade, a see-through panel
  with an edge line, words in a font from the computer, a see-through ellipse, a knob made bigger with its
  name and value centred underneath in other MPC fonts and shown under another name, a knob with its name
  beside it and its value hidden, a longer fader, and a restyled heading.
- **PLAIN** has the same controls exactly as Akai's generator lays them out, to compare against.

What works: the plugin passes the workbench's safety check on the computer. What is not known yet: how the
STYLED page looks on a real MPC. CPU use is that of the starter effect, a fraction of one percent.
